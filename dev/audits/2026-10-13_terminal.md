# État des lieux : Emacs en terminal, terminaux et Claude Code

13 octobre 2026. Ce document ne change plus ; ce qu'il appelle est suivi dans
`dev/plans/2026-10-13_terminal.md`.

## L'objectif

Lou veut à terme travailler surtout dans un terminal : mieux connaître les
outils Linux, être à l'aise en SSH, revoir ses raccourcis, mener plusieurs
sessions Claude Code en parallèle, avec Emacs au centre de l'édition. Quitter
KDE et changer de distribution viendra beaucoup plus tard. Contrainte : la
config actuelle doit continuer de marcher en graphique pendant toute la
transition.

## 1. La config actuelle en terminal (mesuré)

Mesures faites avec `dev/tty-check.py` : un daemon Emacs, un cadre
`emacsclient -t` dans un pseudo-terminal, et les séquences qu'un terminal
envoie pour chaque touche.

- La config se charge sans erreur en `emacs -nw` comme dans un cadre
  `emacsclient -t`. Les réglages propres au graphique (`good-scroll`,
  `pixel-scroll-precision-mode`, `set-frame-font`, barres d'outils) sont sans
  effet en terminal, sans erreur.
- Un même daemon sert en même temps des cadres graphiques (`emacsclient -c`)
  et des cadres terminal (`emacsclient -t`), avec les mêmes buffers.
- Couleurs 24 bits quand `COLORTERM=truecolor` (`display-color-cells` vaut
  16 777 216).
- Toutes les touches testées arrivent, à condition que le terminal envoie la
  bonne séquence :

| Touche         | Séquence reçue                   | Commande                  |
|----------------|----------------------------------|---------------------------|
| C-z            | `^Z`                             | `undo-fu-only-undo`       |
| S-<left>       | `\e[1;2D`                        | `left-char`, sélection    |
| C-<up>         | `\e[1;5A`                        | `backward-paragraph`      |
| C-<prior>      | `\e[5;5~`                        | `centaur-tabs-backward`   |
| C-x C-<left>   | `^X \e[1;5D`                     | `windmove-left`           |
| C-<tab>        | `\e[27;5;9~` ou `\e[9;5u`        | `other-window`            |
| C-<return>     | `\e[27;5;13~` ou `\e[13;5u`      | `compile-all`             |
| C-S-<return>   | `\e[13;6u`                       | `compile-line-and-step`   |
| C-<return>     | `\r` (Konsole par défaut)        | RET (pas `compile-all`)   |

- Seul avertissement : `themes/apropospriate.el` donne `:background nil` aux
  faces `header-line` (ligne 114) et `mode-line-buffer-id` (ligne 168). Emacs
  attend `unspecified` depuis la version 28. Sans conséquence visible.
- Déjà prévu pour le terminal : `xterm-mouse-mode` et le paquet `xclip`. Le
  programme `xclip` n'est pas installé sur ce poste : le presse-papier en
  terminal reste à vérifier.
- Emacs 29.3 sait déjà décoder ces séquences (`term/xterm.el`), écrire dans
  le presse-papier par OSC 52 (`xterm-extra-capabilities`, `setSelection`),
  et charge `term/xterm.el` pour `TERM=xterm-kitty` (mesuré avec
  `tty-find-type`).

## 2. Les terminaux

**Konsole 23.08** (code source, `ViewManager.cpp`, et `default.keytab`) :

- Maj+←/→ changent d'onglet, seulement quand plusieurs onglets sont ouverts.
  Ctrl+Maj+flèche change de panneau quand la fenêtre est partagée.
- Ctrl+Entrée envoie `\r`, comme Entrée.
- Pas de protocole clavier kitty : absent de la liste officielle de kitty.

**Le protocole clavier kitty** permet au terminal de transmettre toutes les
combinaisons de touches sans ambiguïté. kitty le définit ; sa documentation
cite aussi alacritty, foot, ghostty, iTerm2, rio, WezTerm, Warp et le terminal
de Microsoft.

| Terminal  | Protocole kitty | Ubuntu 24.04            | Remarque                                  |
|-----------|-----------------|-------------------------|-------------------------------------------|
| Konsole   | non             | apt 23.08 (installé)    | intégré à KDE                             |
| kitty     | oui (référence) | apt 0.32.2              | onglets, panneaux, notifications          |
| Ghostty   | oui             | snap tiers              | binaires officiels pour macOS seulement   |
| WezTerm   | oui             | absent d'apt            | versions stables rares (source tierce)    |
| foot      | oui             | apt 1.16.2              | Wayland seulement ; ce poste est en X11   |
| Alacritty | oui             | apt 0.13.2              | ni onglets ni panneaux, par choix         |

kitty prend par défaut des touches de la config Emacs : Ctrl+Maj+Entrée
(nouvelle fenêtre) et Ctrl+Maj+←/→ (onglets).

## 3. Claude Code dans un terminal

D'après la documentation de Claude Code :

- Maj+Entrée insère un saut de ligne sans réglage dans kitty, Ghostty et
  WezTerm ; foot et Alacritty 0.16 ou plus demandent Claude Code 2.1.269 ou
  plus. Konsole n'est pas listé. Ctrl+J marche partout.
- Les notifications de bureau partent par défaut dans kitty, Ghostty et
  iTerm2, y compris depuis une session SSH.
- Dans tmux, il faut `allow-passthrough` et `extended-keys`.
- Dans le terminal `eat` d'Emacs, le scintillement se corrige avec
  `CLAUDE_CODE_FORCE_SYNC_OUTPUT=1`.
- Sessions en parallèle : `claude --worktree <nom>` donne à chaque session sa
  propre copie de travail git ; `claude agents` liste les sessions en
  arrière-plan par état (en aperçu de recherche) ; `claude --bg` en lance une.

Relier Claude Code à Emacs :

- **Monet** : Claude Code tourne dans son propre terminal (kitty, Ghostty…) et
  se connecte à Emacs par `/ide`. Demande Emacs 30.
- **claude-code-ide.el** : lance Claude dans un terminal à l'intérieur
  d'Emacs (vterm, eat ou ghostel), diffs dans ediff. Emacs 28.1 ou plus.
- **claude-code.el** : demande Emacs 30. **agent-shell** passe par un
  adaptateur ACP au lieu d'un terminal.
- Emacs 30 sur Ubuntu 24.04 : apt fournit 29.3 ; le snap `emacs` (classique,
  non publié par GNU) et un PPA tiers fournissent 30.2.

## 4. Côté Emacs et outils

- **kkp** (MELPA) : prise en charge du protocole clavier kitty. Demande
  Emacs 27.1, dernière version le 6 juillet 2026, dépôt
  `github.com/benotn/kkp`. S'active par `(tty-setup . global-kkp-mode)`.
  Limite : pendant un `call-process` synchrone, C-g ne l'interrompt pas.
- **TRAMP**, intégré à Emacs, édite un fichier distant
  (`/ssh:serveur:/chemin`) depuis l'Emacs local, sans rien installer sur le
  serveur.
- **ranger** avance peu : 1.9.4 en novembre 2024, après 1.9.3 en décembre 2019.
  **yazi** est actif (26.9.1, septembre 2026), absent d'apt sur Ubuntu 24.04.
  **dired** renomme par édition du buffer (wdired) et marche à travers TRAMP.
