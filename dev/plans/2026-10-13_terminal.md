# Passer au terminal sans casser le graphique

État : en cours, étape 0 faite le 13 octobre 2026.
Constats et sources : `dev/audits/2026-10-13_terminal.md`.

## Principes

- **Le graphique reste l'outil de tous les jours** tant que le terminal n'est
  pas confortable. On bascule le jour où il l'est, pas avant.
- **Un seul `init.el`.** Ce qui ne concerne que le terminal s'active dans
  `tty-setup-hook` (lancé à l'ouverture de chaque cadre terminal) ou derrière
  `(display-graphic-p)`. Un même daemon sert les cadres graphiques et
  terminal : `emacsclient -c` et `emacsclient -t` partagent les buffers.
- **Mesurer à chaque étape** : `python3 dev/tty-check.py` après chaque
  changement d'`init.el`, et dans le terminal lui-même, `cat -v` puis la
  touche, pour voir ce qu'il envoie.
- **Chaque étape est réversible**, et chaque nouveau paquet entre dans
  `package-selected-packages`.

## Étapes

0. **État des lieux** (fait) : la config marche déjà en terminal ; seul le
   terminal doit envoyer les bonnes séquences.

1. **kitty, réglé pour Emacs et Claude Code**
   - L'installer par apt (0.32.2 avec `kitty-terminfo`), choisi le
     13 octobre 2026 : mis à jour avec le système, on changera si une
     fonction manque.
   - `kitty.conf` : police Hack 15 et couleurs `#1c1c1c` / `#E0E0E0` comme
     Emacs ; retirer les raccourcis qui prennent les touches d'Emacs
     (Ctrl+Maj+Entrée, Ctrl+Maj+←/→, à inventorier) ; presse-papier OSC 52.
   - `kitty.conf` vit dans un dépôt de dotfiles à créer, séparé de
     `.emacs.d` et public comme lui, pour partager la config. Il accueillera
     plus tard celle du gestionnaire de fenêtres.
   - Vérifier avec `cat -v` : Maj+flèches, Ctrl+Entrée, Ctrl+Maj+Entrée.

2. **Emacs confortable dans kitty**
   - `kkp`, activé par `tty-setup-hook`.
   - Corriger `:background nil` dans `themes/apropospriate.el`.
   - Presse-papier : vérifier le paquet `xclip` sans le programme `xclip` ;
     sinon OSC 52, qui marche aussi en SSH.
   - Vérifier `centaur-tabs`, la souris et les couleurs dans kitty.
   - Utiliser `emacsclient -t` à côté du graphique, noter ce qui gêne.

3. **Claude Code dans kitty**
   - Un onglet kitty par projet ; `claude --worktree <nom>` pour deux tâches
     en parallèle dans un même dépôt ; `claude agents` pour les suivre.
   - Vérifier Maj+Entrée et les notifications de bureau.

4. **Relier Claude Code et Emacs**, une fois les étapes 1 à 3 rodées
   - Soit Emacs 30 (snap ou PPA, à tester d'abord sur une copie de la config)
     et Monet : Claude reste dans kitty et se connecte par `/ide`.
   - Soit `claude-code-ide.el` sur Emacs 29 : Claude tourne dans Emacs.

5. **SSH**
   - TRAMP depuis l'Emacs local pour éditer sur un serveur.
   - Sur un serveur, `emacs -nw` ; `TERM=xterm-kitty` y est souvent inconnu :
     vérifier `kitten ssh` ou un repli sur `xterm-256color`.

6. **Plus tard** : yazi à côté de dired, raccourcis repensés, puis
   gestionnaire de fenêtres et distribution.
