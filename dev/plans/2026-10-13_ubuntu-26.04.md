# Mettre le poste à niveau vers Ubuntu 26.04

État : proposé le 13 octobre 2026, à confirmer par Lou.

## Pourquoi maintenant

Le 13 octobre 2026, `do-release-upgrade -c` propose 26.04.1 LTS. La faire
avant l'inventaire des raccourcis et la config de kitty (plan
`2026-10-13_terminal.md`) évite de faire ce travail deux fois, puisque KDE
passe de Plasma 5.27 à 6.6. Elle apporte par apt, sans snap :

| Logiciel | 24.04 (ici)                  | 26.04          |
|----------|------------------------------|----------------|
| Emacs    | 29.3                         | 30.2           |
| kitty    | 0.32.2                       | 0.45.0         |
| Plasma   | 5.27                         | 6.6            |
| Python   | 3.12                         | 3.14           |
| R        | 4.5.2 (dépôt CRAN)           | 4.5.2          |
| Mesa     | 25.3 et 26.0 (PPA kisak)     | 26.0           |

Versions de 26.04 lues dans Launchpad (`getPublishedSources`, série
`resolute`).

## Ce que Lou lance, dans son terminal

Commandes en root et interactives : à lancer soi-même dans Konsole.

1. **Mettre 24.04 à jour et redémarrer.** Le 13 octobre, 190 mises à jour
   attendaient et le système demandait déjà un redémarrage ;
   `do-release-upgrade` veut un système à jour.
   `sudo apt update && sudo apt full-upgrade`, puis redémarrer.
2. **Sauvegarder.** Aucun outil de sauvegarde n'est installé : copier
   ailleurs les données qui comptent. Puis garder trois listes :
   - `~/.python_env/bin/pip freeze > ~/python_env-requirements.txt`
   - `apt-mark showmanual > ~/apt-manual.txt`
   - `ls /etc/apt/sources.list.d/ > ~/apt-sources.txt`
3. **Le PPA kisak-mesa.** Il fournit une Mesa (26.2.4) plus récente que celle
   de 26.04 (26.0.8), ce qui mélangerait deux sources pendant la mise à
   niveau. Sauf raison de le garder, le retirer avant :
   `sudo apt install ppa-purge && sudo ppa-purge ppa:kisak/kisak-mesa`.
4. **`sudo do-release-upgrade`**, sur secteur, sans autre travail en cours.

## Après

- **Session X11 d'abord** : 26.04 la fournit encore (`kwin-x11` 6.6.4).
  Plasma 6 démarre en Wayland par défaut ; on change une chose à la fois, et
  Wayland se reverra avec le gestionnaire de fenêtres.
- **Dépôts tiers** : la mise à niveau les désactive. Remettre ceux qui servent
  encore, dans leur version pour 26.04 : CRAN (R), QGIS, DBeaver, Element,
  Mattermost, NodeSource, Steam.
- **Python** : recréer `~/.python_env` (3.12 vers 3.14) avec
  `create-python-env`, puis `pip install -r ~/python_env-requirements.txt`.
  Idem pour tout autre venv.
- **R** : 4.5 des deux côtés, la bibliothèque `~/R/x86_64-pc-linux-gnu-library/4.5`
  reste valable ; réinstaller les paquets compilés qui ne se chargent plus.
- **Klipper** : vérifier qu'il démarre toujours (`~/.config/klipperrc`, voir
  « Hors dépôt » dans `CLAUDE.md`).
- **Emacs 30.2** : retester la config (`dev/tty-check.py`, C-z, Python, R,
  export PDF), refaire les mesures de démarrage, puis mettre à jour
  `CLAUDE.md` (Emacs 29.3), `dev/decisions.md` (versions d'Emacs et de kitty)
  et le plan du terminal.
